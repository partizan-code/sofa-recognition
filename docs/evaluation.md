# Методика экспериментов и проверки

[К обзору проекта](../README.md)

## Статус оценки

Приложение реализует сбор и сравнение результатов пяти режимов. Сравнительный
отчёт на независимой размеченной выборке пока не опубликован; лучший метод
по точности, скорости и стоимости не выбран. Офлайн-тесты проверяют программную
логику, но не измеряют качество ответов реальных AI-моделей.

## Метрики качества

Метрики рассчитываются отдельно для модели мебели, цвета и конфигурации.

| Метрика | Определение |
|---|---|
| Accuracy | Правильные ответы / известные значения; отказы считаются ошибками |
| Coverage | Определённые ответы / известные значения |
| Answered accuracy | Правильные ответы / определённые ответы среди известных значений |
| TOP-5 recall | Доля фото с известной моделью, для которых она присутствует среди кандидатов |

При пустом знаменателе метрика не определена. Строки сравниваются без учёта
регистра и пробелов по краям; словаря синонимов цветов нет. `null` в разметке
исключает параметр из оценки, а не обозначает диван вне каталога.

Для качества берётся последний результат каждого SHA-256 фото в эксперименте:
повторный просмотр не увеличивает размер выборки. Изменение значимых для режима
настроек модели, промпта или каталога создаёт новый эксперимент. Для Vision
учитывается и палитра цветов. В сводке можно выбрать общую выборку нескольких
экспериментов.

## Время и стоимость

Время — полное локальное время обработки, включая preprocessing, поиск и HTTP.
В средние время и стоимость API входят только запуски полностью без кэша;
смешанные запуски доступны в журнале. Повторные запуски учитываются в расходах.

Цена берётся из `usage.cost`. Неизвестная цена — `null`; попадание в локальный
кэш означает $0 новых расходов. Стоимость индексации хранится отдельно рядом
с индексом в `.build.json` и в сводку распознавания не включается.

Показанные расходы относятся к успешным сохранённым запускам. Расходы на оборванные
или невалидные ответы нужно сверять с биллингом OpenRouter. Отчёт индексации отражает
последнюю сборку, а не накопительный биллинг.

## Порядок независимой оценки

1. Подготовьте эталонный каталог и отдельный набор фотографий с известными параметрами.
   Добавьте сложные ракурсы, разное освещение и диваны вне каталога.
2. Разделите данные для подбора порога и итоговой оценки. Начальный cosine-порог
   0.0 не откалиброван; similarity не является вероятностью.
3. Постройте индексы Cohere и Voyage, отдельно сохраните расходы на индексацию.
4. Запустите пять режимов на одной выборке с зафиксированными настройками.
   Для оценки API-времени и стоимости включите обход кэша.
5. Сопоставьте accuracy, coverage, answered accuracy и TOP-5 recall на общих фото.
   Отдельно разберите отказы, ошибки запросов и случаи вне каталога.
6. При публикации укажите размер и состав выборки, настройки моделей, пороги,
   дату эксперимента, время и расходы. Скриншоты и примеры ответов должны быть
   получены из реального запуска; иллюстрации формата следует обозначать отдельно.

Самопроверка каталога исключает точные копии по SHA-256, включая файлы с разными
именами. Перекодированные и визуально близкие дубликаты не выявляются автоматически,
поэтому самопроверка не заменяет независимый набор.

## Автоматические проверки

```sh
mise run check
```

Задача последовательно выполняет Ruff, проверку форматирования и pytest.
Тесты используют искусственные изображения, временные файлы, тестовый ключ
и `httpx.MockTransport`; реальный HTTP-транспорт запрещён autouse fixture
в [tests/conftest.py](../tests/conftest.py).

Проверяются пять режимов, cosine, уникальность моделей, исключение копий,
инвалидация индекса и кэша, `null`, схема Vision и палитра цветов, метрики,
диагностика ошибок и переключение фотографий через Streamlit AppTest.

При готовой `.venv` проверки можно запустить напрямую. Windows, PowerShell:

```powershell
.\.venv\Scripts\ruff.exe check --no-cache .
.\.venv\Scripts\ruff.exe format --check --no-cache .
.\.venv\Scripts\python.exe -B -m pytest -p no:cacheprovider -q
```

macOS:

```sh
.venv/bin/ruff check --no-cache .
.venv/bin/ruff format --check --no-cache .
.venv/bin/python -B -m pytest -p no:cacheprovider -q
```
