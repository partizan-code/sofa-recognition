## Реализовано

- Пять режимов: Vision Only, Cohere Embeddings, Voyage Embeddings, Cohere + Vision,
  Voyage + Vision. Настройки моделей в config.py и интерфейсе, редактируемый промпт.
- Слайд-шоу со стрелками/выбором фото, автоматический запрос при переключении,
  исходное фото и эталон рядом, TOP-5, структурированный JSON с null.
- Загрузка отдельного фото, отдельный тестовый набор, самопроверка каталога.
- Построение отдельных индексов NumPy для провайдера и модели; уникальные модели
  по максимальному cosine; L2-нормализация, проверка размерности и подписи каталога.
- Embeddings: image_url data URL, search_document/search_query; без Vision другие
  параметры не копируются из эталона, остаются null. Порог cosine настраивается.
- Vision: исходное фото + подписанные карточки моделей, до трёх ракурсов на модель;
  strict JSON Schema + Pydantic; в гибриде используются только TOP-5 retrieval.
- Исключение точных копий исходного фото по SHA-256 из retrieval и Vision-эталонов.
- Pillow: автоповорот по EXIF, прозрачность на белом фоне, уменьшение и JPEG.
- Атомарный файловый кэш проверенных ответов; ключ полного запроса, модели,
  промпта и изображений. Повторная индексация продолжает работу через этот кэш.
- Пакетное сравнение методов, обход кэша для замера, экспорт JSON.
- Журнал запусков, точность/coverage/answered accuracy по параметрам, TOP-5 recall,
  время и стоимость, выбор экспериментов и сравнение по общим фотографиям.
- Успешные запуски учитываются в расходах, средние время/цена — только полностью
  без кэша. Неизвестная цена остаётся null. Индексация учитывается отдельно.
- Автоматическая загрузка .env при запуске Streamlit; переменные процесса приоритетны.
- Централизованный Loguru сохранён. Без локальных нейросетей, обучения и векторной БД.

## Данные и ограничения

- Каталог — существующий локальный снимок Google Sheets; синхронизация не добавлялась.
- `data/test/` и test.json пользователь ещё не предоставил. Формат описан в README.
- null в ground truth означает неизвестную разметку, а не заведомо чужую модель.
- Цвет сравнивается строково без регистра/краевых пробелов; синонимы не нормализуются.
- Порог cosine не калиброван, сходство не является вероятностью.
- Исключаются одинаковые байты; перекодированные/близкие дубликаты не обнаруживаются.
- Стоимость есть только если API её вернул. Расходы на невалидные/оборванные запросы
  нужно сверять с OpenRouter. Отчёт индексации описывает последнюю сборку.
- Все каталоги runtime внутри data/, .cache/, .venv и .env исключены из Git.
- Лучший метод пока не выбран: нет реальных результатов точности, скорости и стоимости.
