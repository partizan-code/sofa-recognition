# sofa-recognition: особенности проекта

## Контекст и навигация

Локальный экспериментальный Streamlit MVP для распознавания мебели и сравнения
Vision, image embeddings и гибридного поиска через OpenRouter.

- [README.md](README.md) — обзор и быстрый запуск.
- [docs/README.md](docs/README.md) — техническая документация.
- [docs/PROJECT_STATUS.md](docs/PROJECT_STATUS.md) — текущее состояние и открытые задачи.
- [docs/architecture.md](docs/architecture.md) — потоки данных и ответственность модулей.
- [docs/evaluation.md](docs/evaluation.md) — определения метрик и учёт расходов.

## Архитектурные особенности

- Сохраняйте общий pipeline в `recognition.py` для UI и пакетных экспериментов;
  `ui.py` отвечает за интерфейс, `evaluation.py` — за сравнение результатов.
- Поддерживаются пять режимов: Vision Only, Cohere Embeddings, Voyage Embeddings,
  Cohere + Vision и Voyage + Vision. Без Vision цвет и конфигурация — `null`.
  Vision определяет эти параметры по исходному фото, не копирует их из эталона.
- Retrieval использует cosine по L2-нормализованным векторам NumPy и возвращает
  до пяти уникальных моделей. Порог отказа применяется только без Vision;
  в гибридном режиме Vision получает эталоны кандидатов retrieval.
- Точные копии исходного фото исключаются из поиска и Vision-эталонов по SHA-256.
  Это не защита от всех визуально близких дубликатов.
- При изменении запросов, preprocessing или каталога учитывайте подпись индекса,
  ключи API-кэша и идентификаторы экспериментов. Подробности — в архитектуре.
- Модель результата проверяется JSON Schema и Pydantic в `schemas.py`;
  палитра и настройки находятся в `config.py`. Файловый JSON хранится через `storage.py`.

## Данные, запуск и проверки

- Python 3.13 выбирает mise, `.venv` и зависимости из `uv.lock` обслуживает uv.
  Существующие задачи: `mise run setup`, `mise run start`, `mise run check`.
- Каталог, фотографии, индексы, кэш и результаты находятся в локальном `data/`;
  их форматы описаны в [docs/usage.md](docs/usage.md). Для примеров используйте
  синтетические данные, не содержимое пользовательского каталога.
- Построение индексов и распознавание вызывают OpenRouter; автораспознавание
  по умолчанию включено и может отправлять платные запросы при смене фото.
- Офлайн-проверки используют тестовый ключ, временные файлы и `httpx.MockTransport`.
  Сохраняйте запрет реального HTTP в `tests/conftest.py`; новые проверки должны
  соблюдать ту же изоляцию. Для правок только документации достаточно статической проверки.
- При описании результатов различайте проверку программной логики и качество AI.
  Методика общей выборки, кэша и отдельного учёта индексации задана в `docs/evaluation.md`.
